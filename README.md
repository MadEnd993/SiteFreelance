Жемчуг — сайт гостевого дома
Сайт-визитка с формой онлайн-бронирования для гостевого дома «Жемчуг» (Краснодарский край, Геленджик). Гость оставляет заявку через форму на сайте — она сохраняется в БД и уходит на почту администратору; администратор видит все заявки в отдельной админ-панели.

Стек:
Frontend (frontend/): React + TypeScript, Vite, Tailwind-классы и инлайн-стили.
Backend (backend/): Go, chi (роутер), PostgreSQL через pgx, отправка email через SMTP.
Админ-панель (admin.html): статическая HTML-страница, отдельно от основного React-приложения.

Структура:
siteGood/
frontend/ — React-приложение (форма бронирования), внутри public/admin.html — админ-панель со списком заявок
backend/ — Go API, backend.go, папка env/ с data.env (переменные окружения, не в репозитории)

Что уже работает
Форма бронирования на главной странице: имя, телефон, даты заезда и выезда, число гостей, категория номера, пожелания, мессенджер для связи. Сохранение заявки в PostgreSQL. Уведомление администратора по email при новой заявке. Просмотр всех заявок в admin.html. Удаление заявки через API, DELETE /api/bookings/{id}.

В разработке и известные ограничения:
Админ-панель без авторизации — admin.html сейчас открыт для любого, кто знает URL, логина и пароля нет. Это первое, что нужно закрыть перед реальным запуском, иначе заявки гостей с именами и телефонами доступны всем.
Нет удаления заявок из интерфейса админки — эндпоинт DELETE в API есть, а кнопки для этого в admin.html пока нет.
Нет валидации телефона и дат на бэкенде — сейчас проверяется только, что поля не пустые.
Секреты в data.env работают только локально, для деплоя их нужно будет завести в переменных окружения хостинга или CI, сам файл .env в репозиторий не входит.
Тестов пока нет ни на фронте, ни на бэке.
Деплой не настроен, проект пока рассчитан на локальный запуск.

Запуск локально:
Backend: перейти в папку backend, скопировать env/data.env.example в env/data.env и заполнить своими значениями, выполнить go mod tidy, затем go run backend.go.
Frontend: перейти в папку frontend, выполнить npm install, затем npm run dev.
Админ-панель после сборки будет доступна как статический файл /admin.html на том же хосте, что и фронтенд.
